# Restaurant Management System (C++)

## Project Title
Restaurant Management System

## Description
This is a console-based restaurant management system built using C++. It allows users to manage menu items, take orders, and calculate bills.


## Features
- Add and manage menu items  
- Take customer orders  
- Calculate total bill  
- Simple console-based interface  

## Concepts Used
- Functions  
- File handling  

## Purpose
This project was developed to practice C++ programming.
